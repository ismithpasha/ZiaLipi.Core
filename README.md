# ZiaLipi.Core

The phonetic Bangla typing engine of the **ZiaLipi** keyboard. Type Bangla the
way it sounds, in Latin letters:

```
ami banglay gan gai   →   আমি বাংলায় গান গাই
```

C# / .NET 10, no dependencies, no network access. Licensed under the
[Mozilla Public License 2.0](LICENSE).

## What it does

- **Phonetic conversion**: the widely used phonetic rules (`k` = ক, `kh` = খ,
  `T` = ট, `O` = ও, `rri` = ঋ …), case-sensitive where it matters.
- **Dictionary suggestions**: words are matched through all the spellings a
  Latin word could stand for, with Bangla suffixes (`bangladeshe` → বাংলাদেশে)
  and autocorrect.
- **Layered dictionaries**: the engine ships with a base dictionary, and
  further word lists or a different candidate order plug in through
  `ISuggestionExtension`. The ZiaLipi keyboard uses this to add its own
  dictionary of 270,000+ more words (430,000+ in total) and optional
  word-frequency ranking. More words will be added over time.
- **Remembers choices**: the candidate a user picks is offered first next time.
  Kept only in memory or in a local file you choose.
- **Typing sessions**: works out the smallest edit (backspaces + text) to turn
  what is on screen into the chosen candidate, for keyboards that type into
  other applications.

## Usage

```csharp
using ZiaLipi.Core.Phonetic;
using ZiaLipi.Core.Suggestions;
using ZiaLipi.Core.Typing;

// Plain conversion
string text = PhoneticParser.Default.Parse("ami banglay gan gai"); // আমি বাংলায় গান গাই

// Suggestions for a word (feed it the word as it grows, one key at a time)
var builder = new SuggestionBuilder(new CandidateSelections());
Suggestion s = builder.Suggest("tomar");
// s.Words: তমার, তোমার …   s.PrevSelection: index to pre-select

// A typing session: returns the edit to apply to the target text box
var session = new TypingSession(builder);
TextEdit edit = session.Type('k');   // Backspaces = 0, Insert = "ক"
edit = session.Type('i');            // Backspaces = 0, Insert = "ি"  → কি
session.Commit();                    // word finished (space, enter …)
```

To remember choices between runs, pass a file path:
`new CandidateSelections(@"C:\path\learned-words.json")`.

## Build and test

```
dotnet test ZiaLipi.Core.slnx
```

The tests include *golden* tests: outputs recorded from the original
JavaScript engine, which the C# engine must reproduce exactly.

The data files in `src/ZiaLipi.Core/Data/` are generated by
`node tools/phonetic-data/convert.mjs`, which also records the golden outputs.

## Bangla / বাংলা

ZiaLipi কীবোর্ডের ফোনেটিক ইঞ্জিন। ইংরেজি অক্ষরে উচ্চারণ অনুযায়ী লিখলে বাংলা হয়, অভিধান থেকে
শব্দ সাজেশন আসে, প্রত্যয় যুক্ত হয় এবং অটো-কারেক্ট হয়। ইঞ্জিনের সাথে একটা মূল অভিধান আছে।
অতিরিক্ত অভিধান `ISuggestionExtension` দিয়ে যুক্ত করা যায়। ZiaLipi কীবোর্ড এভাবেই নিজস্ব
অভিধান যোগ করে, যাতে আরও ২.৭ লাখের বেশি শব্দ আছে (মোট ৪.৩ লাখের বেশি)। সামনে ধীরে ধীরে
আরও শব্দ যুক্ত হবে। ইঞ্জিন কোনো
নেটওয়ার্ক ব্যবহার করে না, টাইপ করা কিছুই কোথাও পাঠানো হয় না। লাইসেন্স: Mozilla Public License 2.0।
